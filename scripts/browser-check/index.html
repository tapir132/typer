What this check measures
Final text, key presses and releases, modifiers, browser input events, and timing. Shared-key properties and complete event order are reported separately: corrections and overlapping presses can change the sequence without changing a key's properties. A match applies to this passage and browser. It does not certify human input or hide macOS event-source information. “Trusted” means Safari dispatched an event; it does not prove a physical keypress.
Fixed delivery checks use steady timing. Natural rhythm runs the production generator with three repeatable seeds and default settings. Your keyboard sample is kept separate from generation; it is never used to tune these runs. Compare every seed, rather than choosing the closest one. This does not evaluate a learned profile.
Physical input is your label, not something this page can authenticate. Keyboard samples stay in this tab until you export. Typer uses fixed test passages; its automated reports are saved locally. This check currently targets the U.S. keyboard layout. Spellcheck and autocorrection are disabled here to isolate event delivery. Normal websites may behave differently, especially with Tab, input methods, and rich-text editors.
